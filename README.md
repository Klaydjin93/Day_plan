# План дня

Виджет для Android: по дате телефона показывает КБЖУ на сегодня, тренировку и список того, что подготовить к передаче тренеру. Данные — JSON недельного плана (schema `plan-day/1`), который выпускается при закрытии недели вместе с HTML-планом.

Приложение работает офлайн: файл плана копируется внутрь при загрузке. В репозитории нет личных данных — планы сюда не кладутся (см. `.gitignore`).

## Что умеет

- **Виджет**: дата, КБЖУ, сессии дня со временем и 1–2 ключевыми строками, чек-лист с галочками. Список прокручивается, тап по шапке открывает приложение. День меняется сам после полуночи.
- **Приложение**: полный день — питание с заметками, таблицы сессий, чек-лист, правила недели; листание на другие дни; список загруженных недель.
- **Загрузка плана**: тап по JSON-файлу → «Открыть с помощью» → «План дня», или «Поделиться» файлом, или кнопка «Загрузить план».

## Установка

1. Скачать APK из [Releases](../../releases) на телефон и установить (разрешить установку из этого источника).
2. Добавить виджет: долгое нажатие на рабочий стол → Виджеты → «План дня».
3. Загрузить JSON недели.

Обновления — через [Obtainium](https://github.com/ImranR98/Obtainium): «Add App» → адрес этого репозитория → «Add». Obtainium сам увидит новый релиз.

Если виджет не меняет день после полуночи, проверь, что для «План дня» отключена оптимизация батареи — некоторые прошивки откладывают будильники.

## Выпуск версии

Сборка — GitHub Actions (`.github/workflows/build.yml`). Каждый пуш в `main` собирает APK как артефакт; тег `vX.Y.Z` выпускает релиз:

```bash
git tag v0.1.1 && git push origin v0.1.1
```

Для подписи нужны четыре секрета репозитория (Settings → Secrets and variables → Actions):

| Секрет | Что это |
|---|---|
| `KEYSTORE_BASE64` | файл ключа `dayplan-release.jks` в base64 |
| `KEYSTORE_PASSWORD` | пароль хранилища |
| `KEY_ALIAS` | `dayplan` |
| `KEY_PASSWORD` | пароль ключа |

Ключ один на все версии: обновление поверх установленной версии возможно только с тем же ключом. Потеря ключа = переустановка приложения и повторная загрузка плана.

## Формат `plan-day/1`

```jsonc
{
  "schema": "plan-day/1",
  "week": {
    "id": "W22", "start": "2026-10-26", "end": "2026-11-01",   // обязательные
    "title": "…", "subtitle": "…", "plan_file": "…", "plan_version": "v2",
    "generated": "2026-10-26",          // при перевыпуске недели побеждает более свежий
    "nutrition_rules": ["…"]
  },
  "days": [{
    "date": "2026-10-27", "dow": "ВТ",
    "kind": "run | thr | gym | rest",   // цвет дня
    "nutrition": {"type": "…", "kcal": 1950, "protein_g": 185, "fat_g": 60, "carbs_g": 167, "notes": ["…"]},
    "sessions": [{
      "time": "~08:00", "kind": "run | thr | gym | hema", "title": "Зал B", "meta": "…",
      "summary": ["1–2 строки для виджета"],
      "table": {"head": ["…"], "rows": [["…"]]}   // любая таблица: шапка + строки
    }],
    "report": [{"item": "Время дозы", "when": "утро"}]
  }]
}
```

Неизвестные поля игнорируются, поэтому формат можно расширять, не ломая установленное приложение.

## Разработка

```bash
./gradlew assembleDebug            # APK
./gradlew testDebugUnitTest        # тесты
# снимки экрана и виджета (Robolectric + Roborazzi) на своём файле плана:
PLAN_JSON=/путь/к/plan.json PLAN_DATES=2026-10-27,2026-10-28 SHOT_DIR=/tmp/shots \
  ./gradlew recordRoborazziDebug --tests 'app.dayplan.*Shots'
```

Стек: Kotlin, Jetpack Glance 1.1 (виджет), Jetpack Compose (приложение), kotlinx.serialization. minSdk 26.

Шрифты: Bebas Neue и IBM Plex (SIL Open Font License 1.1, тексты лицензий — в `licenses/`). В Bebas Neue нет кириллицы, поэтому он используется только для цифр.
